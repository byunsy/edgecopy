# Edgecopy

Edgecopy is a computational method for estimating aggregate and paralog-specific copy numbers of paralogous genes using exome sequencing data from multiple samples.

### What does Edgecopy do?

Accuractely detecting copy number variants (CNVs) in paralogous genes using short-read sequencing data is challenging due to short-read mapping ambiguity and extensive copy-number variation. Edgecopy addresses this problem by:

1. Modeling background read depth across multiple samples using a beta-binomial framework.
2. Estimating aggregate copy numbers (agCN) using both point estimates and hidden Markov models.
3. Decomposing aggregate copy numbers into paralog-specific copy numbers (psCN) using paralogous sequence variant (PSV) information.

Edgecopy is designed for exome sequencing data and focuses on detecting both rare and common CNVs in duplicated loci.

### Quick Start (10 minutes)

```
BAM/CRAM files
      ↓
edgecopy depth   (background read depth modeling)
      ↓
edgecopy agcn    (aggregate copy number estimation)
      ↓
edgecopy pscn    (paralog-specific copy number estimation)
```

Edgecopy includes a small demo dataset that can be run end-to-end in under 10 minutes.

#### 1. Calculate background read depth
```
edgecopy depth \
--input data/1KGP.EUR.bam.fp.list \
--output EUR-depth \
--reference data/ref/hg38.ref.fa \
--hom-table data/homology-table/hg38.bed.gz \
--exon-list data/exons/exons.hg38.bed 
```

#### 2. Estimate aggregate copy numbers
```
edgecopy agcn \
--input data/1KGP.EUR.bam.fp.list \
--depth EUR-depth \
--output EUR-agcn \
--hom-table data/homology-table/hg38.bed.gz \
--loci-list data/loci/loci.hg38.list
--reference data/ref/hg38.ref.fa 
```

#### 3. Estimate paralog-specific copy numbers
```
edgecopy pscn \
--input data/1KGP.EUR.bam.fp.list \
--output EUR-pscn \
--loci-list data/loci/loci.hg38.list \
--reference data/ref/hg38.ref.fna \
--hom-table data/homology-table/hg38.bed.gz \
--agcn-dir EUR-agcn 
```

### Test dataset

A small 1000 Genomes Project dataset is provided in the demo-dataset/ directory for testing and benchmarking. It includes the following:
- A list of example input file-paths for the 16 BAM files
- A duplicated locus and its genomic positions
- A BED file containing genomic positions for ~185,000 exons 
- A TSV file containing the read counts mapped to the ~185,000 exons for the 16 samples

Please see [demo-dataset](demo-dataset/) for full instructions.
